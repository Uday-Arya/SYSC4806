# SYSC 4806

All the labs for my SYSC 4806 Software Engineering Lab course

## Lab 1

Created a maven project with 2 Java classes. \
The AddressBook class holds a list of objects of the type BuddyInfo. \
The BuddyInfo class consists of the Name and PhoneNumber of the buddy. \
Wrote test functions with jUnit to test both classes.

## Lab 2

Reused the AddressBook and BuddyInfo classes. \
Persisted them in an in-memory SQLite database. \
Used JPA to define entities and defined persistence using XML. \
Wrote JPQL queries to fetch persisted data to test it works.

## Lab 3

Same as lab 2 but using Spring Data JPA and persisting data in a H2 database.
